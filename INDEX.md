# DSA Practice

Every category is a folder with two files: a **README.md** indexing the problems
solved, and a **NOTES.md** explaining the techniques, the intuition, and what to
drill next. `Concepts` below counts the write-ups in each `NOTES.md` -- a category
with problems but no concepts is one where I solved things without learning them.

| Command | Does |
|---------|------|
| `/dsa-add <url>` | start a problem: pick the category, scaffold the file, hint ladder rather than a solution |
| `/dsa-note` | write a technique into the category's `NOTES.md` and stamp the problem header |
| `/dsa-review <file>` | check correctness, complexity vs constraints, and this repo's C++ traps |
| `/dsa-index` | rebuild these tables, backfill headers, report where practice is thin |

Categories, routing rules and the metadata format live in
[.claude/dsa/taxonomy.md](.claude/dsa/taxonomy.md).
